① 什么是 JSON

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式， 它的语法就是 JS 对象和数组的子集，但不是完整的 JS 代码—— 它只能表达数据，不能表达函数、方法等行为。 下面这段就是一个合法的 JSON 字符串： 

{
  "name": "魏鹏",
  "age": 20,
  "hobbies": ["篮球", "前端开发"],
  "score": null,
  "vip": true,
  "address": { "city": "北京", "zip": "100000" }
}

JSON 里只能出现 6 种合法值：

"字符串" 123 true / false null { 对象 } [ 数组 ]

② JSON ≠ JS 对象

JSON 语法是 JS 的严格子集，有几个必须记住的差异：

特性JSONJS 对象
键名必须双引号 "key"可省略引号、可单引号
值类型仅 6 种（右表中 6 个）含函数、Symbol、undefined、Date 等
注释❌ 不允许 // 或 /* */✅ 允许
尾逗号❌ 最后一项后不能有 ,✅ 允许
undefined❌ 不存在（会被忽略或变成 null）✅ 存在
循环引用❌ JSON.stringify 抛错✅ JS 可以互相引用
