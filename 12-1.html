CSS 变量演示

使用 :root 自定义属性统一管理颜色、间距、圆角等设计令牌

变量声明（:root）

:root { --bg: #f5f0e8; --card-bg: #ffffff; --text: #2c3e50; --accent: #3498db; /* 更多变量... */ }

在 :root 中声明的变量全局可用，通过 var(--变量名) 引用。修改变量值即可全局生效，便于主题切换与维护。

色彩变量应用

主色

var(--accent)

暖色

var(--accent-warm)

绿色

var(--accent-green)

紫色

var(--accent-purple)
