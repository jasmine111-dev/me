LENGTH UNITS

Web 前端长度单位

CSS 中的长度单位分为绝对单位与相对单位两大类。绝对单位固定不变，相对单位则随上下文（父元素、根元素或视口）动态变化，是响应式布局的核心。

绝对长度单位

固定尺寸，不随环境变化

像素 px

最常用的屏幕单位，1px 对应屏幕上的一个物理像素点（CSS 逻辑像素）。

96pxwidth: 96px

英寸 in

印刷单位，1in = 96px，常用于打印样式表。

1in = 96pxwidth: 1in

厘米 cm

1cm ≈ 37.8px，物理长度单位，多用于打印。

1cm ≈ 37.8pxwidth: 1cm

毫米 mm

1mm ≈ 3.78px，1cm = 10mm。

10mm = 1cmwidth: 10mm

点 pt

印刷常用，1pt = 1/72in ≈ 1.333px。

72pt = 1inwidth: 72pt

派卡 pc

1pc = 12pt = 16px，印刷排版单位。

6pc = 1inwidth: 6pc

相对长度单位

随上下文动态计算

em em

相对于父元素字体大小，嵌套时会逐层叠加（复合效应）。

1em = 20px
1em = 25px
1em = 31.25px

rem rem

相对于根元素（html）字体大小，不会嵌套叠加，适合整体缩放。

2rem 4rem

百分比 %

相对于父元素的对应属性值计算。

父元素的 50%

视口单位

相对于浏览器视口大小

vw / vh / vmin / vmax

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。调整浏览器窗口大小，观察下方色块变化。

--视口宽度 (vw)
--视口高度 (vh)
--vmin
--vmax
50vw
25vh

其他单位

特殊场景使用

ch ch

相对于当前字体中 "0" 字符的宽度，常用于限制文本行宽。

0000000000
10ch ≈ 10 个字符宽width: 10ch

ex ex

相对于当前字体中 "x" 字符的高度，实际使用较少。

1ex ≈ x 字符高度height: 1ex

lh lh

相对于当前元素的行高（line-height）。

1.5lhheight: 1.5lh
