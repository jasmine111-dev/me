LESSON 13 · 练习四

SVG 图标下导航

使用 SVG symbol + use 标签引用图标，实现移动端自适应宽度的固体底部导航栏，包含数字徽章与右上角红点提醒。

实现说明

SVG symbol

SVG 内联定义

将 iconfont.js 中的 SVG symbol 提取到页面内联 <svg> 中，每个 symbol 拥有独立 id，通过 <use href="#id"> 引用，无需额外 HTTP 请求。

<symbol id="魏鹏_icon-pingguo" viewBox="0 0 1024 1024">

图标着色控制

SVG 图标使用 fill: currentColor 继承父元素文字颜色，通过 CSS 的 color 属性即可统一控制图标颜色，实现激活态与非激活态的切换。

.魏鹏_nav-icon svg { fill: currentColor; }

底部导航结构

使用 position: fixed + left: 0; right: 0; bottom: 0 实现全屏宽度固定定位，flex 布局使 4 个导航项等宽自适应，适配任意屏幕宽度。

.魏鹏_nav { position: fixed; width: 100%; }

数字徽章与红点

徽章使用绝对定位 position: absolute 配合 top/right 偏移，叠加在图标右上角。数字徽章为圆角矩形，红点为圆形小点，均使用醒目的红色背景。

.魏鹏_num-badge { position: absolute; top: -6px; right: -16px; }

安全区域适配

通过 env(safe-area-inset-bottom) 适配 iPhone 全面屏底部小黑条，避免导航内容被遮挡，保证在各移动端设备上完美显示。

padding-bottom: env(safe-area-inset-bottom, 0px);
